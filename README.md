# Орбита

Единый цифровой кабинет студента вымышленного «Университета Будущего».
Решение задачи «Цифровой деканат будущего» хакатона **MGIMO×AI Challenge** (ноябрь 2026).

Код целиком написан ИИ-агентами (Claude Code) под руководством автора: идеи, решения, ревью и проверка — человек, код — агенты.

> Концепт для конкурса, не официальный сервис какого-либо вуза. Все люди, оценки и документы вымышлены.

## Как это сделано с ИИ

Подробно — в PDF «Описание процесса создания», приложенном к работе. В репозитории лежат сами файлы, по которым работали агенты:

- [`CLAUDE.md`](CLAUDE.md) — точка входа для каждого нового агента: что прочитать, правила, проверки
- [`docs/vision.md`](docs/vision.md) — миссия, принципы и журнал решений
- [`docs/ui-guide.md`](docs/ui-guide.md) — дизайн-система для агентов: токены, компоненты, «Не делай»
- [`docs/security.md`](docs/security.md) — вход, хранение паролей, разграничение доступа
- [`docs/notifications.md`](docs/notifications.md) — устройство центра уведомлений
- [`docs/jury-review.md`](docs/jury-review.md) — аудит «глазами жюри» на середине работы
- [`docs/licenses.md`](docs/licenses.md) — сторонние шрифты, иконки, библиотеки и их лицензии

## Безопасность

- Пароли — только хеш Argon2id с солью и «перцем» из переменных окружения.
- Пользователь берётся из серверной сессии, не из запроса; чужая заявка, работа или бронь отвечает «не найдено».
- Ключи и секреты — только в env на сервере, в репозитории их нет.
- 21 сценарий автопроверок (Playwright), в большинстве — подделанные запросы к чужим данным.

## Запуск локально

Нужен Node.js 20.9+.

```bash
cd web
npm install
cp .env.example .env        # AUTH_PEPPER: openssl rand -base64 32
npm run db:push
npm run db:seed
npm run dev                 # http://localhost:3000
```

Автопроверки: `npm run build`, затем `node scripts/<раздел>-check.mjs` (например, `office-check.mjs`) — сценарий сам поднимает сервер.

## Стек
