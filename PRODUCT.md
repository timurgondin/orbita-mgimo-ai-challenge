# PRODUCT

Краткий продуктовый контекст для дизайн-инструментов (impeccable). Подробно: [docs/vision.md](docs/vision.md), дизайн: [docs/design.md](docs/design.md).

- **Продукт:** «Орбита» — единый цифровой кабинет вымышленного «Университета Будущего» (студенты, преподаватели, учебный офис). Концепт для хакатона MGIMO×AI Challenge.
- **Пользователи:** студенты 17–23 лет, чаще с телефона, между парами; преподаватели и сотрудники учебного офиса — с компьютера.
- **Сценарий использования:** быстрые заходы «что у меня сейчас/дальше», проверка оценок и дедлайнов, заказ справок; вечером — домашки и материалы.
- **Режим поверхности:** Operate (интерфейс приложения). Исключения с режимом Experience: онбординг первокурсника, экран входа.
- **Тон:** спокойный, уверенный, премиальный, без канцелярита. Обращение на «ты».
- **Визуальный мир:** тёмная тема по умолчанию (нейтральный графит, не чёрный) + светлая. Уровень Apple / Linear / Notion. Фирменные детали: точечное поле, живая сфера-ассистент, засечный шрифт для приветствий.
- **Запреты:** реальные данные и логотипы вузов; «нейрослоп» (одинаковые карточки, градиентный текст, свечения).
